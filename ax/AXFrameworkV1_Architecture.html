AX Framework v1 Unity

  • · Framework — UI Lifecycle Design
  • · Architecture — State-Driven UI
  • · Pattern — MVC / MVVM Oriented
  • · System — Runtime State Container
  • · Data — Stat Binding Flow
  • · Pipeline — Reusable Unity Framework
Unity Framework R&D

Contribute

  • · AX 게임 개발을 위한 Unity 공통 프레임워크를 설계하고 정리한 개인 프로젝트
  • · UI_Base에 InitOnce, MakeDirty 기반 구조를 도입하고, MVC / MVVM 계열 설계와 State Container 개념을 반영해 런타임 상태 중심의 UI 갱신 구조를 정리
  • · UI가 씬 오브젝트가 아닌 상태 데이터를 바라보도록 설계해 재사용성과 유지보수성을 높인 개발 파이프라인 구축

구조

Singleton<T>
 ├─ GameManager
 ├─ DataManager
 ├─ UIManager
 ├─ ObjectManager
 ├─ PoolManager
 ├─ ResourceManager
 ├─ EventManager
 ├─ SaveManager
 ├─ SceneManager
 ├─ SoundManager
 ├─ LocalizationManager
 ├─ AdsManager
 └─ IAPManager

UI_Base
 ├─ UI_Scene
 │   └─ UI_DevScene
 └─ UI_Popup
     ├─ UI_DetailPopup

 ├─ Creature
 │   ├─ Player
 │   ├─ Monster
 │   └─ Npc

IDataLoader<Key, Value>
 ├─ ItemDataLoader
 └─ TextDataLoader

IResourceLoader
 ├─ AddressablesLoader
 └─ ResourceLoader

Outcome

  • · UI_Base 기반 공통 UI 구조 설계
  • · UI_Scene / UI_Popup 분리 및 공통 UI 관리 흐름 구성
  • · Singleton<T> 기반 매니저 공통화
  • · GameManager / DataManager / UIManager / ObjectManager / PoolManager / ResourceManager 구축
  • · Addressables / Resources 이중 대응 가능한 리소스 로더 구조 정리
  • · CSV → JSON 변환 기반 데이터 파이프라인 구축
  • · 이벤트 기반 UI 갱신 흐름 구성
  • · Save / Load 및 Config ScriptableObject 구조 정리
  • · 최근에는 InitOnce, MakeDirty, 상태 기반 UI 갱신 구조로 고도화 진행
