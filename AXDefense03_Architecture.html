스크립트 시스템 — 5대 핵심 기둥

Config & Data

게임 전역 설정 및 ScriptableObject 기반 스탯/아이템 정의

Managers

런타임 게임 상태, 흐름, 풀링을 제어하는 중앙 싱글톤 시스템

Controllers

플레이어, 몬스터, 상호작용 객체의 실질적 로직 및 AI

UI

Z-index 스택 기반의 씬(Scene) 및 팝업(Popup) 인터페이스

Map & FX

절차적 타일맵 생성, 그리드 관리 및 시각적 피드백 (DOTween, 파티클)

↑ Utils & Events (공통 기반)

비파괴적 기획 데이터 파이프라인

Editor (엑셀 데이터) → ScriptableObject (유니티 에셋화) → JSON Serialization (런타임 로드용 저장) → DataManager & Game Load (읽기 전용 런타임 모델)

모듈화된 중앙 제어 매트릭스

네 그룹의 매니저가 EventBus (Pub/Sub)를 중심으로 느슨하게 결합.

게임 흐름 제어

GameManager · RunManager · DayNightManager · WaveManager

객체 / 공간 관리

SpawnerManager · PoolManager · BuildManager · LightManager

메타 및 데이터

DataManager · SaveManager · CurrencyManager · ProfileManager

유틸리티

EventManager · UIManager · SoundManager · SceneManager · Localization · Coroutine

크리처 아키텍처 & 월드 오브젝트

Creature Base

공통 체력/상태이상 → Player / Monster / NPC로 분기. 타격·투사체 궤적 연산 분리, 몬스터 접촉 데미지 개별 처리.

AI 타겟팅 우선순위

1순위 Player → 2순위 Caravan → 3순위 Installable 구조물 (Proximity 기반)

Interactable (월드 배치)

채집 자원 노드, 제작대, 캐러밴 — 플레이어가 다가가 액션을 취하는 대상

Installable (플레이어 배치)

횃불·캠프파이어(빛/열), 나무 함정·자동 포탑(방어선) — 그리드 기반 건설, 파괴 시 재료 드롭

레이어 기반 Z-Index UI 스택

Overlay / System

게임 오버 화면, 디버그 아이템 스폰 UI, 데미지 플로팅 텍스트

Popup UI (Systems)

인벤토리(드래그&드롭), 크래프팅, 장비 슬롯, NPC 거래, 일시정지 — 스택 기반 열기/닫기 제어

Scene UI (HUD)

게임 메인 HUD, 가상 조이스틱, 생존 스탯, 공격 버튼, 퀵슬롯

모든 UI는 UI Base를 상속하며, 클릭/드래그 입력 이벤트 디스패처를 통해 이벤트를 중앙 처리.

비주얼 폴리시 & 외부 패키지

DOTween / URP 2D Light

UI 트랜지션 트위닝, 횃불·캠프파이어 빛 반경 및 실시간 Flicker 효과

Particles & Pooling

상태이상 파티클 오버레이, 설치 미리보기 피드백, 재생 완료 FX 자동 풀 반환

수익화

IronSource LevelPlay (광고 중재), Unity IAP (인앱 결제)

에셋 / 입력

Addressables, TextMesh Pro, Unity Input System
